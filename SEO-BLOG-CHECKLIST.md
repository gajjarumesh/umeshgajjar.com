## 📝 **Blog Writing SEO Checklist** 

Use this checklist when creating new blog posts:

### **Content Optimization**
- [ ] **SEO Title** (50-60 characters, include main keyword)
- [ ] **SEO Description** (150-160 characters, compelling summary)
- [ ] **Featured Image** (1200x630px for optimal sharing)
- [ ] **Tags** (3-5 relevant tags, use existing when possible)
- [ ] **Categories** (1-2 primary categories)
- [ ] **SEO Keywords** (comma-separated, 5-10 keywords)

### **Content Quality**
- [ ] **Minimum 800 words** for better ranking potential
- [ ] **Clear H1 title** (only one per post)
- [ ] **H2/H3 subheadings** for structure
- [ ] **Internal links** to other blog posts/pages
- [ ] **External links** to authoritative sources
- [ ] **Alt text** for all images
- [ ] **Clean URL slug** (use post title, keep it short)

### **Technical Checks**
- [ ] **Content is unique** and not duplicated
- [ ] **Images are optimized** (WebP format, compressed)
- [ ] **Post is set to 'published' status**
- [ ] **Published date is set** correctly
- [ ] **Author name** is filled

## 🔧 **Advanced SEO Recommendations**

### **Image SEO**
- Use descriptive filenames (e.g., `react-hooks-tutorial.webp`)
- Add structured data for images in posts
- Create image sitemaps for better indexing

### **Core Web Vitals**
- Optimize Largest Contentful Paint (LCP) < 2.5s
- Minimize First Input Delay (FID) < 100ms  
- Reduce Cumulative Layout Shift (CLS) < 0.1

### **Content Strategy**
- Create content clusters around main topics
- Build topic authority with comprehensive guides
- Update and republish old content regularly
- Create pillar pages linking to related posts

### **Link Building**
- Guest post on relevant tech blogs
- Share posts on social media platforms
- Participate in developer communities
- Create linkable assets (tools, resources, guides)
